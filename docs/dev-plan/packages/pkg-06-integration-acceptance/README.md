# pkg-06 竖切联调、失败态与验收

状态：completed  
依赖：pkg-03、pkg-04、pkg-05

## 目标

把前面五包收成一条能演示、能复验的主链路。本包可以修胶水缺陷，但不能借机做下一轮功能。

## 改动范围

**可以改**

- 各层联调、错误文案、状态刷新
- Vitest、Playwright、Rust 测试
- 本目录计划状态和验收清单

**不能做**

- 快速切换、全局快捷键、安装包
- 待办、时间线、窗口预览
- 文件夹 / URL / 命令
- macOS、Agent

## 交付内容

1. Playwright：空状态创建、添加软件、重复添加、Markdown/图片、工作区隔离、窗口关闭提示、保存失败。全部是 mock command，文件头标明“不是 Windows 置前证据”。
2. `cargo test` 覆盖存储、去重、删除、画布恢复。原生桌面测试不进默认集。
3. Windows 人工清单：`windows-manual-acceptance.md`（记事本或 Edge：启动、最小化恢复、关闭重开、坏路径、删工作区后软件还在）。
4. 「已自动 / 仍需人工」对照表：`verification-matrix.md`。窗口置前、最小化恢复、真扫描标「仍需人工」。

## 竖切完成标准（必须能演示）

1. 第一次打开是空的，能新建工作区。
2. 能从扫描结果或手动 exe/快捷方式添加软件。
3. 启动后当前工作区出现卡片；再点同一软件不重复绑定。
4. 点卡片能切到真实窗口；窗口关掉后有提示并能重开。
5. 白板 Markdown / 图片重启后还在。
6. 两个工作区的软件和白板互不污染。
7. 删除工作区或移出软件，真实软件还在。

前 3、5、6 条的 UI/数据规则可自动演示（mock）。第 4、7 条的真实窗口与真实进程必须走人工清单。
