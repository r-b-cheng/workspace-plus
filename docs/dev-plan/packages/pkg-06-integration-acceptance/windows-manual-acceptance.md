# Windows 人工验收清单

本清单验证真实桌面能力。Playwright / Vitest / 默认 `cargo test` **不能**代替这里的勾选。

实施包未在本机代跑记事本或 Edge；请在真实 Windows 会话里勾选。

## 新建与切换工作区

- [ ] 第一次打开若无工作区，能看到空状态并新建「验收工作区 A」
- [ ] 再新建「验收工作区 B」，侧栏可在 A/B 之间切换
- [ ] 重启应用后进入最近使用的工作区

## 扫描与添加

- [ ] 打开「添加软件」，刷新后能看到本机开始菜单中的常见项（记事本、Edge 等；机器不同结果不同，重点是列表可理解）
- [ ] 在工作区 A 添加记事本或 Edge：真实软件被启动，当前工作区出现一张卡片
- [ ] 再点同一软件：不出现第二张卡，界面显示已在工作区
- [ ] 手动添加一个有效 `.exe` 或 `.lnk` 成功
- [ ] 手动添加一个不存在的路径：有明确失败原因（路径无效 / 未找到），不是无反馈

## 窗口置前与关闭重开（必须人工）

- [ ] 把已添加软件窗口最小化，再点产品里的卡片或「切换窗口」：窗口恢复并尝试置前
- [ ] 把窗口放到其他窗口后面，再点卡片：窗口切到前台
- [ ] 手动关掉该软件窗口，再点卡片：出现「窗口已关闭」一类提示，并有「重新打开」
- [ ] 点「重新打开」后真实软件再次启动，仍是同一张卡
- [ ] 若系统拒绝置前：看到明确失败原因，而不是无反馈

## 白板

- [ ] 在工作区 A 新建 Markdown 卡片，输入标题、列表或链接，预览正常
- [ ] 粘贴或拖入一张图片，画布出现图片卡片
- [ ] 拖动卡片后等待顶栏变为「已保存」
- [ ] 关闭并重新打开应用：Markdown 正文、图片卡片和位置仍在 A

## 隔离与删除语义

- [ ] 工作区 B 看不到 A 的软件卡片和白板卡片
- [ ] 在 B 添加另一个软件和一张不同的 Markdown，切回 A 后 A 的内容未被污染
- [ ] 删除 B 时，确认文案写明只删工作区数据、不卸载软件、不关闭真实窗口
- [ ] 删除 B 后：真实软件进程仍在（若当时开着）、系统里该软件仍可从开始菜单打开、产品软件库里仍能搜到该项
- [ ] 从工作区移出软件：真实窗口不因此被关掉，软件未被卸载

## 失败态

- [ ] 移走或重命名一个手动添加的 exe 后再启动：提示路径不存在或目标无效
- [ ] 保存失败时（例如人为让磁盘/权限失败，或开发时注入失败）：顶栏是「保存失败」且可重试，不会继续显示「已保存」

## 本清单明确不做

- 快速切换面板、可配置全局快捷键
- 安装包 / 签名 / 自动更新
- 待办卡片、操作时间线、窗口截图预览
- 文件夹 / URL / 命令启动
- macOS、费曼 Agent
