# pkg-07 全局设置与可配置快捷键

状态：completed  
依赖：pkg-06  
可并行：无

## 目标

把快速切换快捷键做成可配置、可持久化、可失败反馈的设置。默认候选是 `Ctrl+O`，但不能写死。本包只负责设置和注册，不画搜索浮层。

## 改动范围

**可以改**

- `app_settings` 读写、设置 DTO、`get_app_settings` / `update_app_settings`
- 全局快捷键注册 / 注销
- 最小设置弹窗和新的 `src/features/settings/`
- 顶栏设置按钮接到这个弹窗，不再只打开重命名

**不能做**

- 快速切换搜索面板
- 改启动、聚焦、扫描实现
- 文件夹 / URL / 命令、截图预览、软件内嵌

## 交付内容

1. 设置里能读到当前快捷键、注册状态、最近失败原因。
2. 改快捷键后写库并重新注册。冲突或系统拒绝时界面说明原因，允许再改。
3. 按下已注册组合只发出 `quick-switch:open`，供下一包打开面板。
4. 前端只走 `settingsApi`，不直接 `invoke`。

## 子任务

| ID | 子任务 | 完成标准 |
|---|---|---|
| s07-01 | 设置 DTO 与默认值 | 默认 `Control+KeyO`，字段含注册状态 |
| s07-02 | 设置 command | SQLite 持久化，非法组合校验失败 |
| s07-03 | 注册 / 注销 | 启动和保存后都会按当前值注册 |
| s07-04 | 只发打开事件 | Rust 不搜软件、不聚焦窗口 |
| s07-05 | 最小设置弹窗 | 能改快捷键并看到成败 |
| s07-06 | 测试 | 默认值、校验、失败态有自动测试 |

## 验收

- 重启后快捷键还在
- 能改成非 `Ctrl+O` 的组合
- 注册失败不把应用打挂
- 没有快速切换面板
