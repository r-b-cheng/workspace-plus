# pkg-08 快速切换面板

状态：pending  
依赖：pkg-07

## 目标

快捷键或测试入口打开轻量 launcher。输入几个字就能定位当前工作区软件，键盘选中后切换窗口、重新打开，或把软件库里的项添加并打开。

## 改动范围

**可以改**

- 新建 `src/features/quick-switch/`
- 监听 `quick-switch:open`
- 复用现有 launch / focus / add
- 必要时只加搜索 command，不改启动语义

**不能做**

- 别名/备注编辑页（P1）
- 截图预览、软件内嵌
- 在 Rust 里重新实现启动
- 把 HWND 或热键注册细节塞进前端

## 交付内容

1. 浮层：搜索框、结果列表、动作标签（切换窗口 / 重新打开 / 添加并打开）。
2. 默认先出当前工作区软件，再补未加入的软件库结果。
3. 匹配名称、别名、用途备注、最近窗口标题。字段已有即可，本包不提供编辑入口。
4. Vitest 覆盖过滤和三种动作。系统热键留给 pkg-09 人工验。

## 子任务

| ID | 子任务 | 完成标准 |
|---|---|---|
| s08-01 | store 与结果模型 | 三种 action 分清 |
| s08-02 | 浮层与键盘 | 输入、方向键、Enter、Esc |
| s08-03 | 接到现有动作 | 不新写启动链路 |
| s08-04 | 事件与测试入口 | 快捷键事件和 hook 都能打开 |
| s08-05 | Vitest | 过滤和动作分发有测试 |

## 验收

- 无工作区时面板不崩
- 三种结果动作文案和调用都对
- 前端没有平台热键细节
