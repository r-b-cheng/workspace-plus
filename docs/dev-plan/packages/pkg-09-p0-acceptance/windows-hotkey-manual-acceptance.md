# Windows 全局热键人工验收清单

本清单验证**系统级**快捷键和真实外部窗口。Playwright hook（`window.__E2E_OPEN_QUICK_SWITCH__`）、Vitest 和 mock command **不能**代替这里的勾选。

`tests/e2e/quick-switch-panel.spec.ts` 绿了，只说明前端面板和设置读写在 mock 下可走通。**不能**当成：

- 全局热键已注册成功
- 真人按键能打开面板
- 已切到真实外部窗口

实施包未在本机代跑系统热键或记事本 / Edge；请在真实 Windows 会话里勾选。

## 注册与改绑（设置页）

- [ ] 启动后能看到默认快捷键（界面或设置里为 `Ctrl+O` / `Control+KeyO`）的注册状态（已注册 / 冲突 / 系统拒绝 / 未注册）
- [ ] 在设置里改成**非** `Ctrl+O` 的组合（例如 `Alt+K` / `Alt+KeyK`），保存后注册状态更新，应用不崩溃
- [ ] 重启应用后仍是上次保存的组合，而不是又回到写死的 `Ctrl+O`
- [ ] 与其它软件冲突或系统拒绝注册时，界面有原因；应用不崩溃；可以再改成别的组合

## 真人按键（不能用 hook 代替）

- [ ] **真人按下**已注册组合后，快速切换面板打开。不能用顶栏「快速切换」按钮或 `__E2E_OPEN_QUICK_SWITCH__` 代替这一条
- [ ] 面板里选记事本或 Edge，Enter 后切到真实外部窗口（不是只改产品里的卡片状态）
- [ ] 把该软件窗口关掉后，面板对应项显示「重新打开」；Enter 后真实软件再次启动，产品里仍是同一张卡
- [ ] 搜一个尚未加入当前工作区、但软件库里有的项，动作是「添加并打开」；Enter 后该项加入当前工作区并真实启动

## 本清单明确不做

- 用 Playwright hook 冒充本页任何一条已通过
- 窗口截图预览、待办、时间线
- 文件夹 / URL / 命令
- 软件内嵌、macOS 真实现、Agent、同步、协作、插件
