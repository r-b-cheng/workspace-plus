# pkg-10 同一软件的多窗口管理

状态：completed  
依赖：pkg-09  
可并行：pkg-11

## 目标

Chrome、VS Code 这类软件经常同时开多个窗口。本包让用户按窗口标题选择聚焦，不再只绑最近一个主窗口。

## 改动范围

**可以改**

- `native_windows` 与聚焦 command
- 平台枚举同一进程的多个顶层窗口
- 软件卡片上的窗口列表

**不能做**

- 把窗口嵌进产品界面
- 读软件内部文档
- 把 HWND 传给前端

## 交付内容

1. 一个工作区软件可有多条窗口记录。
2. `list_workspace_app_windows` / `focus_native_window`。
3. 卡片可展开窗口列表；默认点击仍切最近窗口。

## 验收

- 两个窗口能分开切
- 关掉一个不影响另一个
- 前端看不到 HWND

真桌面请勾 `chrome-windows-manual-acceptance.md`。自动测试只用 mock，不要当成已切过真实 Chrome。
