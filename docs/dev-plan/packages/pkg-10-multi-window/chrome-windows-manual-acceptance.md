# pkg-10 双窗口人工清单

在真实 Windows 上验证同一软件的两个窗口。`cargo test` / `npm test` 只用 mock，不能代替这一步。

不要写必须自动打开真实 Chrome 的测试。

## 环境

| 项 | 填写 |
|---|---|
| 日期 | |
| 验收人 | |
| 构建 | 例如 `npm run tauri dev` |
| 被测软件 | Chrome / 其他： |

## 清单

- [ ] 当前工作区加入 Chrome（或同类多窗口软件），再打开**两个**顶层窗口（标题能区分即可）
- [ ] 卡片点「窗口列表」能看到两行标题；界面没有 `HWND`、没有数字句柄
- [ ] 点第二行只切到那一扇；点卡片标题或「切换窗口」仍切最近一扇
- [ ] 关掉其中一扇后，列表里不再出现那一行；另一扇仍可切；不要假装关掉的那扇还在
