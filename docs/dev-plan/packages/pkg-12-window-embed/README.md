# pkg-12 可选的外部窗口内嵌（实验）

状态：completed  
依赖：pkg-10

## 目标

这是 P2 里争议最大的一项。产品默认仍然是“切到真实窗口”。本包只做 Windows 上按软件打开的预览宿主。做不成的窗口必须回退，不能假装软件在产品里运行。

## 改动范围

**可以改**

- 每个工作区软件的 `embedEnabled`，默认关
- Windows 宿主实验
- 失败回退到现有聚焦

**不能做**

- 默认内嵌全部软件
- 改掉“点卡片切外部窗口”这条主路径
- 读软件内部内容、注入键盘
- macOS 内嵌

## 交付内容

1. 用户显式打开“在本窗口预览”后才尝试内嵌。
2. 不支持的窗口立刻失败并切回真实窗口。
3. 退出预览后，外部窗口还在。

## 验收

- 关掉开关的软件行为与现在完全一样
- 失败原因可读
- 前端业务层看不到 HWND
