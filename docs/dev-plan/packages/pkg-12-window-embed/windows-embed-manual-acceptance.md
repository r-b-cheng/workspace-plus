# pkg-12 Windows 在本窗口预览 — 人工验收

默认路径仍是点卡片 /「切换窗口」切到真实窗口。本清单只验收 **opt-in** 的预览实验。

## 默认关

- 新加入工作区的软件，`embedEnabled` 为关。
- 未勾选「在本窗口预览」时，卡片上没有「预览」按钮。
- 点卡片或「切换窗口」只聚焦真实窗口，不会 SetParent。

## 记事本可试

1. 启动经典记事本（`notepad.exe`），把它加入当前工作区并保持运行。
2. 勾选「在本窗口预览」，再点「预览」。
3. 预期：记事本出现在本产品客户区的预览宿主里；中间栏卡片和右侧白板都还在。

Windows 11 新版记事本若是 UWP / ApplicationFrame 宿主，应立刻失败并回退聚焦，不要装成功。

## 应立刻失败并回退聚焦

对下列窗口打开「在本窗口预览」再点「预览」，应看到可读原因，并切到真实窗口：

- Chrome / Edge / 其他 Chromium 窗口
- Electron 应用（VS Code、Slack 等常见类名）
- 以管理员或更高完整性运行的窗口
- UWP / `ApplicationFrameWindow`

失败横幅直接显示后端 `reason`，不要假装已经在产品里运行。

## 退出预览

- 点「退出预览」后，外部窗口回到独立状态，仍然开着。
- 不要关掉外部软件。
- 再点卡片仍可聚焦该窗口。

## 不要验收的内容

- 读取外部软件内部文档
- 向外部窗口注入键盘或鼠标
- macOS 内嵌
- 默认给所有软件打开预览
