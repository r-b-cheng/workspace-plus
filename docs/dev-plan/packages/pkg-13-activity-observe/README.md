# pkg-13 可选的窗口活动观察

状态：pending  
依赖：pkg-10  
可并行：pkg-14

## 目标

用户打开开关后，产品只记录已经能从窗口枚举看到的事：哪个窗口到了前台、标题是什么、什么时间。这不是键鼠监听，也不是读软件内部。

## 改动范围

**可以改**

- 默认关闭的观察开关
- 低频前台窗口采样
- 本地 `activity_events` 和时间线 UI

**不能做**

- 键盘钩子、剪贴板常驻、后台截屏
- 读外部文档或网页正文
- 把数据传到网上
- 默认打开

## 交付内容

1. 设置页清楚写出观察范围。
2. 打开后右侧能看到窗口切换时间线。
3. 关掉立刻停。

## 验收

- 新库默认无观察
- diff 里没有钩子和上报
- 事件只有标题 / 进程名 / 时间
