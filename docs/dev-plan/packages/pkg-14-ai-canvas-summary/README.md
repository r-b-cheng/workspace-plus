# pkg-14 画布内容的手动 AI 总结

状态：pending  
依赖：pkg-09  
可并行：pkg-13

## 目标

用户自己点一次，产品根据当前画布生成一份可编辑总结。不读外部软件，不在输入时自动打模型。费曼追问放到 pkg-15。对着白板边聊边画放到 pkg-22，本包只打通 provider 和上下文抽取。

pkg-21 的 scene 完成后，上下文应加上图形摘要；本包实现时若 21 还未做，先抽卡片和连线即可。最终形态见 `docs/product/whiteboard-drawing-and-ai.md`。

## 改动范围

**可以改**

- 画布上下文抽取
- AI provider / 密钥设置
- `summarize_canvas` 和总结卡片

**不能做**

- 自动实时请求
- 读外部软件
- 费曼问答循环
- 把密钥写进白板

## 交付内容

1. 可选范围：当前节点 / 视口 / 全画布。
2. 手动生成一张 Markdown 卡片。
3. 没配 provider 时指引去设置。

## 验收

- 默认不联网打模型
- 结果可改、可删
- 密钥不进画布
