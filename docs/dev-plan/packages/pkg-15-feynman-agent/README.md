# pkg-15 基于画布的费曼学习 Agent

状态：pending  
依赖：pkg-14

## 目标

帮用户检查“我能不能用自己的话讲清楚”，而不是再写一份摘要。材料只来自用户放进画布的内容。

P2 最终形态是对话 + 可读可画的白板（pkg-22）。本包仍只做费曼会话，不实现通用聊天，也不实现往 scene 上落笔。规格总述见 `docs/product/whiteboard-drawing-and-ai.md`。

## 改动范围

**可以改**

- 新建 `src/features/agent/`
- `run_feynman_session`
- 建议卡片落回画布

**不能做**

- 读外部软件
- 每次输入都打模型
- 覆盖用户原文
- 插件市场

## 交付内容

1. 追问、复述检查、概念拆解、知识缺口。
2. 结果是可删的普通卡片。
3. 默认手动触发。

## 验收

- 能看清这次分析了哪些节点
- 删卡片即撤销
- 默认不自动请求
