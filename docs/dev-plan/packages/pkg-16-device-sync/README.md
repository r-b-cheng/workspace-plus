# pkg-16 工作区导出导入与本机同步准备

状态：pending  
依赖：pkg-09  
可并行：pkg-15

## 目标

跨设备同步的第一刀是可审查的工作区包，不是云账号。用户能把一个工作区带走，在另一台机器导入。软件路径对不上时只标不可用。

## 改动范围

**可以改**

- `export_workspace` / `import_workspace`
- 导出包格式和冲突报告

**不能做**

- 自建同步服务器
- 实时多端
- 多人同时写同一库
- 把密钥或 HWND 打进包

## 交付内容

1. 导出：工作区、软件关联、画布、图片文件。
2. 导入：新工作区或指定覆盖，并给出缺失路径清单。

## 验收

- 本机导出再导入，白板还在
- 其他工作区不被碰
- 包内无密钥
