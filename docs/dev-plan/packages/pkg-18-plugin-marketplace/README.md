# pkg-18 本地插件清单与加载

状态：pending  
依赖：pkg-09  
可并行：pkg-16

## 目标

“插件市场”的第一刀是本机插件，不是商店。用户把插件放到本地目录，看权限，自己打开。插件不能直接操作窗口，也不能读密钥。

## 改动范围

**可以改**

- `src-tauri/src/plugins/`
- 本机扫描、启用开关、白名单能力

**不能做**

- 在线市场、登录、付费、远程安装
- 插件直接调 Win32
- 插件读 LLM 密钥

## 交付内容

1. `plugin.json` 格式和权限枚举。
2. 设置里列出本机插件，默认全关。
3. 一个示例插件：往当前画布加一张卡片。

## 验收

- 没有网店
- 越权调用失败
- 坏插件不拖垮主窗口
