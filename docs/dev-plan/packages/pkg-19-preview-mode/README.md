# pkg-19 工作区预览模式

状态：completed  
依赖：pkg-12

产品规格：[`docs/product/workspace-preview-mode.md`](../../../product/workspace-preview-mode.md)

## 目标

预览不再是卡片上的开关实验，而是中间栏的第二种模式。顶部搜索和应用栏留下，下面变成当前这一个程序的真实窗口，可以操作。点应用标签仍然切到系统窗口。

## 改动范围

**可以改**

- 中间栏布局：`dispatcher` / `preview`
- 应用标签上的预览 / 退出
- 卡片去掉勾选和预览按钮
- `embed_workspace_app_window` 不再检查 `embedEnabled`
- 已嵌入窗口按宿主表面更新 bounds

**不能做**

- 点标签就进预览
- 一次嵌多个窗口
- macOS 内嵌
- 把 HWND 传给前端
- 做 pkg-13 及之后的包

## 交付内容

1. 运行中标签一键预览；失败回调度台并聚焦。
2. 预览时隐藏概览和卡片，宿主铺满应用栏以下。
3. 退出、切工作区、移出软件时释放窗口，外部程序还在。

- 预览入口在应用栏，不再藏在卡片勾选里
- 失败不装成功
- 前端看不到 HWND
