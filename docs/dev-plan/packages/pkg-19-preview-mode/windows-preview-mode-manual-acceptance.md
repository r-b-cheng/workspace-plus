# pkg-19 Windows 预览模式 — 人工验收

默认路径仍是点应用标签 / 卡片切到真实窗口。本清单只验收**预览模式**。

## 调度台

- [ ] 打开工作区后中间是概览和卡片，不是预览宿主。
- [ ] 卡片上没有「在本窗口预览」勾选，也没有卡片「预览」按钮。
- [ ] 点应用标签名称、点卡片，只切到系统窗口，产品中间栏仍是调度台。
- [ ] 「+」仍打开添加软件，加入的是系统里已有的软件。

## 进入预览（记事本）

1. 启动经典记事本（`notepad.exe`），加入当前工作区并保持「运行中」。
2. 在应用栏对该标签点「预览」，不要先找任何开关。
3. 预期：
   - 中间栏概览和卡片消失。
   - 顶栏搜索、应用栏、左侧工作区、右侧白板都还在。
   - 记事本窗口铺满应用栏以下的中间栏主体，可以在里面输入文字。
   - 该标签呈预览选中态。

Windows 11 新版记事本若是 UWP / ApplicationFrame，应立刻失败并回退聚焦，不要留空预览框。

## 点标签仍切系统窗口

- [ ] 预览记事本时，点另一个已运行软件的**标签名称**：该软件的系统窗口被聚焦；不要因为点了名称就换预览目标。
- [ ] 要对另一个软件进入预览，必须点它标签上的「预览」。此时记事本应被放出，中间只留下新软件（若新软件嵌得进去）。

## 应立刻失败并回退

对下列窗口直接点应用栏「预览」，应看到可读原因，回到调度台，并切到真实窗口：

- Chrome / Edge / 其他 Chromium 窗口
- Electron 应用（VS Code、Slack 等）
- 以管理员或更高完整性运行的窗口
- UWP / `ApplicationFrameWindow`

不要假装已经在产品里运行。

## 退出与生命周期

- [ ] 点「退出预览」后，中间回到软件卡片；外部窗口独立存在，没有被关掉。
- [ ] 该窗口的位置和大小应回到进入预览之前（或最大化状态与进入前一致），不要突然铺满屏幕或跳到屏幕角落。
- [ ] 再点标签仍可聚焦该窗口。
- [ ] 再点标签仍可聚焦该窗口。
- [ ] 预览中切换工作区：旧窗口被放出，新工作区是调度台。
- [ ] 预览中把该软件移出工作区：预览结束，窗口还在系统里。
- [ ] 拖动左右侧栏或缩放产品窗口：记事本跟着宿主表面变大变小，没有整窗闪烁重嵌。

## 不要验收

- 读取外部软件内部文档
- 向外部窗口注入键盘或鼠标（预览成功后，用户直接点窗口内部操作即可）
- macOS 内嵌
- 打开产品就自动预览某个软件
