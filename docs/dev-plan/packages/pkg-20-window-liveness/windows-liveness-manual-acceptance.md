# pkg-20 窗口关闭及时对账 — 人工验收

默认不要点「窗口列表」去“刷新”。关闭后应自己反映到界面。

## 记事本

1. 当前工作区加入经典记事本，再开**两个**记事本窗口。
2. 展开窗口列表，应看到两行运行中。
3. 关掉其中一扇（任务栏或窗口关闭按钮），**不要**再点产品里的按钮。
4. 预期：关掉的那一行从列表消失；另一行仍可切换；应用栏仍显示运行中。
5. 再关掉最后一扇。预期：标签变成「窗口已关闭」，可重新打开。软件还在工作区。

## Chrome（只测列表，不测预览内嵌）

- [ ] 两个 Chrome 窗口，关掉一个后列表/状态更新，不必先点刷新。

## 预览

- [ ] 若正在预览记事本，关掉那扇记事本：预览退出，回到调度台，不要空框。

## 不要验收

- Edge/Electron 嵌进中间栏操作
- 关窗后软件从工作区消失
- 键盘钩子或活动时间线
