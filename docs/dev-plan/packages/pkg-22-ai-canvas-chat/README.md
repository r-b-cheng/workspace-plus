# pkg-22 白板对话

状态：pending  
依赖：pkg-14、pkg-21  
规格：`docs/product/whiteboard-drawing-and-ai.md`

## 目标

P2 最终形态的第一刀：在当前工作区和 AI 说话。它读卡片、连线和画图层，可以讨论，也可以把新卡片或图形写回白板。

不读外部软件。默认手动发送。费曼提示词仍以 pkg-15 为准，本包不重做那一套。

## 改动范围

**可以改**

- `src/features/agent/` 对话面板
- 画布上下文加上 scene 摘要
- `chat_canvas`：返回文本 + 可选的新卡片 / scene 补丁

**不能做**

- 自动连打模型
- 覆盖用户原文
- 读预览窗口或外部编辑器
- 密钥进白板

## 交付内容

1. 当前工作区对话，能看到本次上下文范围。
2. 模型可以落一张可删的 Markdown 卡片。
3. 模型可以往 scene 里加箭头或框，用户能删掉。

## 验收

- 没配 provider 时有设置指引
- 工作区 A 的对话写不进 B 的白板
- 删掉 AI 写下的卡片/图形即撤销
