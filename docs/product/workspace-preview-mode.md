# 工作区预览模式

记录日期：2026-08-21

本文是预览功能的产品与交互规格。实现以本文为准；与旧文冲突时，旧文里「中间栏永远不能放真实窗口」只适用于**调度台**，不适用于**预览模式**。

开发包：`docs/dev-plan/packages/pkg-19-preview-mode/`。

## 1. 产品决定

工作台有两种用法，共用同一套三栏壳，不是两套独立产品。

| | 调度台（默认） | 预览模式 |
|---|---|---|
| 中间栏顶部 | 工作区名、搜索、添加软件、设置 | 原样保留 |
| 应用栏 | 当前工作区软件标签 +「+」 | 原样保留 |
| 中间栏主体 | 概览 + 软件卡片 | **一个**已运行软件的真实窗口，铺满剩余高度，可直接操作 |
| 左侧工作区列表 | 显示 | 显示 |
| 右侧白板 | 显示 | 显示 |
| 点应用标签 / 卡片 | 切到系统窗口 | 仍切到系统窗口 |
| 何时能操作外部程序 | 不能。中间栏只做管理 | 仅此时可以 |

补充：

- 点应用**默认**仍切到系统窗口。预览不会变成点标签的默认结果。
- 预览一次只接一个程序。换预览目标时，先释放当前窗口，再接入新窗口。
- 「添加软件 / +」只把系统里已有的软件加入当前工作区，不在工作台里创造新程序。
- 白板只属于调度台这一层信息架构：预览时不把白板搬进中间栏，也不藏掉右侧栏。

## 2. 当前实现为什么不合格

pkg-12 把预览做成卡片上的持久开关 + 按钮，宿主是卡片下方一块约 240px 的虚线框。问题是：

1. 进入预览要先勾选再点按钮，路径不直接。
2. 预览没有变成中间栏的一种模式，只是仪表盘里多了一块残缺区域。
3. 概览、卡片仍占着主体，真正窗口没有铺满可操作区域。
4. 宿主视觉框和原生窗口位置容易对不齐，看起来像坏了。

pkg-19 要改的是**进入方式和中间栏布局**，不是再做一个开关。

## 3. 布局

中间栏是纵向 flex：顶部 chrome 不参与伸缩，主体吃掉剩余高度。

```text
调度台
┌─────────┬──────────────────────────────────┬─────────┐
│ 工作区  │ 名称 · 搜索 · 添加软件 · 设置     │ 白板    │
│ 列表    │ [Edge 运行中] [CC Switch] [+]     │         │
│         │ 概览                               │         │
│         │ 软件卡片                           │         │
└─────────┴──────────────────────────────────┴─────────┘

预览模式
┌─────────┬──────────────────────────────────┬─────────┐
│ 工作区  │ 名称 · 搜索 · 添加软件 · 设置     │ 白板    │
│ 列表    │ [Edge 运行中] [CC Switch] [+]     │         │
│         │ ┌──────────────────────────────┐  │         │
│         │ │ 当前预览的真实窗口（可操作）  │  │         │
│         │ │ 铺满中间栏剩余高度            │  │         │
│         │ └──────────────────────────────┘  │         │
└─────────┴──────────────────────────────────┴─────────┘
```

预览模式下：

- 隐藏工作区概览和软件卡片网格。
- 宿主表面占满中间栏在应用栏以下的全部剩余空间（`flex-1 min-h-0`），不要 `min-h-[240px]` 的残缺框。
- 左侧栏、右侧白板、顶栏、应用栏都还在。
- 原生窗口必须和宿主表面在屏幕上重合。侧栏拖宽、窗口缩放后，窗口跟着改尺寸，不要闪一下重新嵌套。

## 4. 交互

应用栏是预览的主入口。软件卡片不再承担预览开关。

### 4.1 应用标签

每个标签分两个命中区，不要合成一个「点一下既聚焦又预览」：

| 命中区 | 行为 |
|---|---|
| 名称 / 状态（标签主体） | 始终 `activateWorkspaceApp`：有窗口则聚焦系统窗口，已关闭则走现有重开提示，未启动则启动。**不进入预览。** |
| 「预览」 | 仅 `status === running` 时出现。点了就进入该软件的预览模式。 |
| 「+」 | 打开添加软件弹窗，把系统已有软件加入当前工作区。 |

正在被预览的标签要有选中态。它的「预览」改成「退出」，或标签旁只保留退出，不要同时出现两个互相打架的按钮。

对另一个已运行软件点「预览」：释放当前预览，把主体换成新软件。一次仍然只有一个。

未运行、启动中、已关闭的软件不显示「预览」。不要为了预览自动启动软件。

### 4.2 软件卡片（只在调度台）

- 点卡片主体 /「切换窗口」：聚焦系统窗口。
- 去掉「在本窗口预览」勾选框和卡片上的「预览」按钮。
- 窗口列表、重新打开、移出工作区保持原样。

### 4.3 进入与退出

进入：

1. 用户点某个运行中标签上的「预览」。
2. 中间栏切到预览模式，先画出铺满的宿主表面。
3. 量完宿主表面相对产品窗口客户区的位置后，再请求把该软件已绑定窗口放进去。
4. 成功：可以在主体里操作该程序。
5. 失败：不要停留在空预览。回到调度台，显示可读原因，并回退聚焦系统窗口。禁止假装软件已经在产品里运行。

退出（任一发生都要释放窗口，外部程序继续独立运行）：

- 点当前预览标签上的「退出」或宿主上的「退出预览」
- 切换到另一个工作区
- 删除当前工作区
- 把当前预览的软件移出工作区
- 工作区被清空

退出后中间栏回到概览 + 卡片。不要关掉外部软件。

### 4.4 明确不做

- 点标签默认进入预览
- 预览里同时并排多个真实窗口
- 把预览做成每个软件的持久偏好（不再用勾选框决定能不能预览）
- 快速切换面板改成进入预览；它仍是聚焦 / 重开 / 添加并打开
- 预览时藏掉白板，或把白板塞进宿主
- 前端出现 HWND / AXUIElement
- macOS 内嵌（失败文案走现有「当前系统不支持」，回退聚焦）

## 5. 文案

沿用包 12 的中文，不要改成「内置浏览器」「在此操作外部软件」「嵌入运行」：

| 用途 | 文案 |
|---|---|
| 标签上的进入动作 | 预览 |
| 退出 | 退出预览 |
| 失败横幅 | 后端返回的 `reason`，原样展示 |
| 调度台概览 | 可以写：预览在应用栏，点「预览」后中间区域会变成该软件的窗口。点标签仍会切到系统窗口。 |

## 6. 状态

前端会话状态即可，不要把「是否正在预览」写成每个软件的持久设置。

```ts
type WorkspaceView = 'dispatcher' | 'preview';

// 已有字段继续用：
// embeddedWorkspaceAppId: 真正嵌进去的软件
// pendingEmbedWorkspaceAppId: 正在请求中的软件
```

规则：

- `preview` 且 `pending`：主体已是宿主（可显示「正在放入窗口…」），卡片已隐藏。
- `preview` 且 `embedded`：宿主可操作。
- 请求失败：`dispatcher`，`embedded` / `pending` 皆空，横幅显示原因。
- 工作区切换：沿用包 12 的释放与 `stillCurrent` 守卫，禁止把上一工作区的预览状态写到下一工作区。

`embedEnabled` 不再作为用户门槛。界面不展示该开关。`embed_workspace_app_window` 不得再因为「未打开在本窗口预览」拒绝。存储里的字段可以留着，本包不删 command、不写迁移删列。

## 7. 宿主与尺寸

原生窗口挂在产品主窗口客户区上（包 12 已有能力）。产品要保证：

1. 宿主表面在预览模式下占据中间栏应用栏以下的全部剩余空间。
2. 传给后端的 bounds 是相对**产品窗口客户区**的物理像素，且与宿主表面重合。不能只拿 WebView 里 `getBoundingClientRect()` 的视口坐标直接 `MoveWindow`。
3. 已经预览成功时，侧栏拖动、窗口缩放、DPI 变化只更新位置和大小，不要先释放再重新 SetParent（会闪）。
4. 一次只有一个嵌入会话。换目标时先释放再接入，失败也不得留下上一扇窗口。

前端仍然只传语义字段：`workspaceAppId`、`hostBounds`。不要把 HWND 传给业务层。

## 9. 验收

自动：

- 调度台点标签 / 卡片只走聚焦或启动，不调用 embed。
- 运行中标签能直接点「预览」，无需勾选。
- 进入预览后概览和卡片消失，宿主存在且占满主体。
- 点另一个软件的「预览」会换目标；点标签主体仍走 activate。
- 退出后回到调度台，并调用 release。
- 失败时不停留在空预览，展示 reason，并回退聚焦。
- 切换 / 删除工作区、移出软件不会把预览状态漏到别处。
- 前端源码和错误 JSON 不含 hwnd。

人工（Windows）：见开发包手工清单。记事本应能铺满中间栏主体并在其中输入；Edge / Electron / UWP / 管理员窗口必须失败并回退，不许装成功。
